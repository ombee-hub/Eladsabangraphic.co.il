# אתר אלעד סבן — עיצוב גרפי

אתר תדמית סטטי (HTML/CSS/JS), בעברית מלאה (RTL), רספונסיבי לנייד. ללא שום תלות בבנייה — פותחים קובץ בדפדפן וזה עובד.

## מבנה הקבצים

```
Eladsabangraphic/
├── index.html        דף הבית
├── about.html        אודותיי
├── projects.html     גלריית הפרויקטים (עם סינון לפי קטגוריה)
├── project.html      עמוד פרויקט בודד — דינמי, משרת את כל 8 הפרויקטים
├── services.html     שירותים (עמוד נפרד)
├── contact.html      צור קשר (טופס + פרטי קשר)
├── images/           כל התמונות — logo-Eladsabangraphic.png (לוגו ראשי) + 8 לוגואי לקוחות + רקעים
├── css/style.css     כל העיצוב + מערכת הצבעים + רספונסיב
├── js/site.js        תפריט נייד, סינון, ונתוני הפרויקטים
└── README.md         הקובץ הזה
```

## איך צופים באתר
- לחיצה כפולה על `index.html` תפתח אותו בדפדפן.
- מומלץ להריץ שרת מקומי כדי שעמודי הפרויקטים (`?slug=`) יעבדו חלק:
  - `python -m http.server` ואז גלישה ל-`http://localhost:8000`

## מערכת העיצוב
- **צבעים (ערכה בהירה, אקסנטים מערכת ה‑Wix המקורית):** רקע `#FFFFFF` · משטחים `#F6F6F5` · טקסט `#141414` · אקסנט מותג: אדום `#ED1C24` (ראשי), כחול `#0088CB`, צהוב `#FFCB05`.
- **פונטים:** `Assistant` בלבד (Google Fonts) — בכל האתר.
- **אייקונים:** Tabler Icons (נטען מ-CDN).
- כל הצבעים מוגדרים כמשתני CSS בראש `css/style.css` (`:root`) — שינוי במקום אחד מחליף בכל האתר.

## עריכת פרויקטים
כל נתוני הפרויקטים נמצאים במשתנה `PROJECTS` שבתוך `js/site.js`. לכל פרויקט:
שם, תחום, תיוגים, תפקיד, תוצרים, תיאור, צבעי מותג (`heroBg`/`heroFg`) ופלטה.
- **הוספת פרויקט:** הוסיפו רשומה ל-`PROJECTS`, הוסיפו את ה-slug למערך `ORDER`, והוסיפו כרטיס ב-`projects.html`.
- **צבעי מותג:** למכבי נתניה והפועל חיפה כבר הוגדרו צבעי המותג האמיתיים. לשאר הוגדרה ערכת ברירת מחדל (כהה+כתום) — מחליפים בקלות.

## החלפת ה-Placeholders בלוגואים אמיתיים
כל הריבועים עם ראשי התיבות (`מ.נ`, `ES` וכו') הם מקומות שמורים ללוגו:
- בגלריה: ה-`<div class="canvas">` בכל כרטיס ב-`index.html` / `projects.html`.
- בעמוד הפרויקט: אזור `.detail-hero` ואזור `.apps`.
מחליפים את הטקסט בתג `<img src="...">` של הלוגו האמיתי.

## העלאה לאוויר (Deploy)
האתר סטטי, אז כל אחסון מתאים:
- **Netlify / Vercel / Cloudflare Pages:** גוררים את התיקייה — וזהו.
- **דומיין:** מומלץ דומיין משלו (למשל `eladsaban.co.il`) במקום כתובת ה-Wix.
