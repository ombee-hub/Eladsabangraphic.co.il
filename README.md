# אלעד סבן — עיצוב גרפי | Elad Saban Graphic Design

אתר תדמית סטטי (HTML / CSS / JS) למעצב הגרפי אלעד סבן, המתמחה במיתוג לארגוני ספורט, עמותות ועסקים.

## מבנה
קבצי האתר נמצאים בשורש ה‑repo:
- `index.html` — דף הבית.
- `css/`, `js/`, `images/` — נכסים.
- דפים נוספים: `about.html`, `projects.html`, `services.html`, `contact.html`, ודפי פרויקטים.

## הרצה
אתר סטטי ללא שלב בנייה — פותחים את `index.html` בדפדפן, או מגישים את התיקייה משרת סטטי.
