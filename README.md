# אלעד סבן — עיצוב גרפי | Elad Saban Graphic Design

אתר תדמית סטטי (HTML / CSS / JS) למעצב הגרפי אלעד סבן, המתמחה במיתוג לארגוני ספורט, עמותות ועסקים.

## מבנה
- `web/` — כל קבצי האתר (דפים, `css/`, `js/`, `images/`).
- דף הבית: `web/index.html`.

## הרצה
אתר סטטי ללא שלב בנייה — פותחים את `web/index.html` בדפדפן, או מגישים את תיקיית `web/` משרת סטטי.
